# sarima-xgboost-komoditas-bawangmerah-surabaya
Perbandingan metode SARIMA dan XGBoost dalam melakukan peramalan harga komoditas pangan di Surabaya Komoditas yang digunakan yaitu Bawang Merah. Analisis mencakup eksplorasi data, pengujian stasioneritas, pemodelan, serta evaluasi hasil peramalan untuk mengetahui metode yang memberikan performa terbaik.
